whatsapp-scheduler is intended to automate sending messages to whatsapp.

# Project Setup
1. Make sure you have python. You can install using command:
```powershell
pip install python
```
2. Install requirements of this project:
```powershell
pip install -r requirements.txt
```
3. You can run the project from `main.py`. To run from cmd, use command:
```powershell
python main.py
```
